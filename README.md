# Bunq-style Bank PWA - Flutter

Moderná mobilná banková aplikácia (Flutter PWA) – žltá #FFD500, dark mode, 3 taby, PIN, QR, platby.

## Features
- Prehľad s eye toggle a idle auto-hide zostatku (60s)
- Karty carousel, block/limity
- QR generator + SQR/SPayd decoder
- Platby, kontakty, analytika
- PIN lock (demo: 1234)
- Dark/light theme
- CSV export
- PWA ready + Vercel deploy config

## Quick start
```bash
flutter pub get
flutter run -d chrome
```
